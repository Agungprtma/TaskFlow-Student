## 🚀 Getting Started

### Installation (5 minutes)

```bash
cd TaskFlow-Student

# 1. Install dependencies
npm install

# 2. Setup environment
cp .env.example .env
# Edit .env with your database URL and GA4 ID

# 3. Setup database
npm run db:setup

# 4. Start server
npm run dev

# Visit http://localhost:3000
```

### First Test Run

1. Open landing page - see hero section with CTA buttons
2. Click "Mulai Atur Prioritas" - go to onboarding
3. Fill form - create user account
4. Dashboard appears - shows stats and recommendations
5. Add a task - fill all fields including deadline and difficulty
6. View task board - see task card with priority badge
7. Drag task - move between columns to update status
8. Click "Mulai Sesi Fokus" - start timer
9. Submit feedback - rate the features

### Database Inspection

```bash
npm run db:studio
# Opens http://localhost:5555 with Prisma Studio GUI
```

## 📝 Key Implementation Details

### Priority Scoring Algorithm

```javascript
// Example: Task with 2-day deadline + high difficulty + high importance + 6 hours
deadline: 30 points (2-3 hari)
difficulty: 30 points (tinggi)
importance: 30 points (tinggi)
estimatedHours: 20 points (>5 jam)
───────────────────────
Total: 110 points → Prioritas Tinggi → "Start today, split into 2 sessions"
```

### Drag-and-Drop Implementation

- HTML5 Drag and Drop API (native, no jQuery)
- dragstart: Add visual feedback
- dragover: Highlight drop target
- drop: Update DB via PATCH /tasks/:taskId/status
- Visual feedback: opacity, borders, shadows, animations

### Analytics Funnel

```
Landing Page View (entry)
    ↓ CTA Click
Onboarding (signup conversion)

Dashboard (first action)

    ↓ Task Status Update

Feedback (product validation)
    ↓ Feedback Submit
```
